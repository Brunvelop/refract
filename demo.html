🔌 RefractClient

Pure HTTP client. No framework required — works in vanilla JS, React, Vue, Lit, tests. Calling summarize() here. The response is your Pydantic model, returned as-is.

import { RefractClient } from '/refract/client.js'; const api = new RefractClient(); // Schemas are auto-loaded and cached on the first call const data = await api.call('summarize', { text: '...', max_words: 5 }); console.log(data); // { summary: "...", words: 5 } ← your Pydantic model // Access the schema (Python type info, resolved from /functions/details) const schema = api.getSchema('summarize'); // schema.parameters → [{ name: 'text', type: 'str', required: true }, ...] // schema.response_schema → { properties: { summary: ..., words: ... } } // Validate before calling (for form UX) const { valid, errors } = api.validate('summarize', { max_words: 5 }); // → { valid: false, errors: { text: 'Required' } }
📡 SSE Streaming  api.stream()

For long-running tasks. The backend yields format_sse("token", ...) events; the client consumes them as an async generator.

import { RefractClient } from '/refract/client.js'; const api = new RefractClient(); for await (const { event, data } of api.stream('stream_words', { text })) { if (event === 'token') show(data.chunk); if (event === 'complete') done(data.message); }
