One Python function. Four interfaces. Three JS layers. All in one demo.

✨ Zero-config  generator.js

Load one script — <auto-{funcName}> elements are registered automatically. No configuration, no code.

<!-- 1. Load the generator (once, in <head>) --> <script type="module" src="/refract/generator.js"></script> <!-- 2. Drop any <auto-{funcName}> anywhere in the page --> <auto-add></auto-add> <auto-search></auto-search>
🃏 Layer 3  AutoFunctionElement

Ready-to-use card UI. Specify func-name — form fields are generated from the schema.

<script type="module" src="/refract/element.js"></script> <auto-function-element func-name="greet"></auto-function-element> <auto-function-element func-name="bmi"></auto-function-element>
🎮 Layer 2  AutoFunctionController

Extend the controller to build custom UIs. State, validation, and API calls are handled for you. Only render() is yours.

import { AutoFunctionController } from '/refract/controller.js'; class BmiCalculator extends AutoFunctionController { render() { const bmi = this.result?.bmi; return html` <input @change=${e => this.setParam('weight_kg', e.target.value)} /> <button @click=${this.execute}>Calculate</button> ${bmi ? html`<big>${bmi}</big> — ${this.result.category}` : ''} `; } } customElements.define('bmi-calculator', BmiCalculator);
🔌 Layer 1  RefractClient

Pure HTTP client. No Lit, no components. Works in vanilla JS, tests, or any framework. Calling the async-only summarize function here.

import { RefractClient } from '/refract/client.js'; const api = new RefractClient(); const result = await api.call('summarize', { text: '...', max_words: 5 }); console.log(result); // { summary: "...", words: 5 }
📡 SSE Streaming  RefractClient.stream()

For long-running tasks. The backend yields format_sse("token", ...) events; the client consumes them as an async generator.

for await (const { event, data } of api.stream('stream_words', { text })) { if (event === 'token') show(data.chunk); if (event === 'complete') done(data.message); }
